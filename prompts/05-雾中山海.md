# 05 雾中山海

栏目口号：**山在雾里，人在画里。** 每周四发布，编号 MIST-001 起。和"水墨山海异兽"的区别：这里是**写实胶片摄影感**，不出现神兽，只有浓雾、遗迹和一个很小的人。

## 视觉规范

| 元素 | 规定 |
| --- | --- |
| 色调 | 冷灰蓝、低饱和，只留一处朱砂红 #C0392B 作点缀 |
| 朱砂点缀 | 红伞 / 红灯笼 / 红色山门 / 红衣人，每张只用一种 |
| 构图 | 山水画的"三远"：近处建筑、中景雾、远景层层山影 |
| 人物 | 很小、背对镜头，占画面不到 3% |
| 质感 | 胶片颗粒 + 轻微晕光，参考 Portra 400 / 灰调电影感 |

## 遗迹与地貌清单

| 类型 | 可用变量 |
| --- | --- |
| 建筑 | an ancient stone pagoda · a temple gate · a lone pavilion · a hanging temple built on a cliff face · a broken stone arch bridge · a wooden watchtower |
| 地貌 | layered misty peaks · a pine forest on a cliff · a quiet river with a wooden boat · karst mountains along a river · terraced fields in fog · a frozen lake |
| 参考地 | Huangshan granite peaks and pines · Zhangjiajie sandstone pillars · Guilin karst river · Wuyuan village in spring fog · Wudang mountain golden summit |

```

```


**海报 3:4（可让 GPT Image 直接写诗句）**

```
A vertical 3:4 poster, analog film photography. [Guilin karst mountains along a quiet river] dissolving into dense morning fog, with a single wooden boat carrying a figure in a [vermilion] cloak. The top 35% is vast white fog like an empty scroll. In that empty area, write the Chinese text "[云深不知处]" vertically, in a thin elegant brush-calligraphy style, small and in dark grey, with a tiny red square seal below it. No other text, no watermark.
```

> 画面中文偶尔会出错字，生成后务必逐字核对；有错就让它重写，或者改成后期加字。

## 文案与互动

- **标题模板**：用一句古诗做标题，如「只在此山中，云深不知处」「楼台烟雨中」，古诗无版权问题，而且自带搜索流量。
- **互动钩子**：「评论区接下一句」或「你家乡的哪座山也该被雾藏起来」。
- **系列拓展**：二十四节气版，每个节气一张，天然有发布时间节点。

## 后期要点

- 用 HSL 只保留红色饱和度，其余颜色降到接近黑白。
- 雾不够浓时，用白色渐变从中部往上叠一层，不透明度 20–40%。
- 可在留白处用竖排小字标诗句和编号，加一枚朱红小印章做标志。
