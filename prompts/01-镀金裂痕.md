# 01 镀金裂痕

栏目口号：**碎过的地方，会发光。** 每周一发布，编号 KIN-001 起。这个栏目卖的是情绪：破碎之后的修复与重生。画面是入口，文案才是涨粉点。

## 视觉规范

| 元素 | 规定 |
| --- | --- |
| 背景 | 纯黑 #0A0A0A，不出现任何场景 |
| 主体 | 白瓷 / 白大理石 / 石膏，色值约 #F2EEE6 |
| 金线 | 主金 #D4A84B，高光 #F3D88A；金线要"微微发光"，不要涂料感 |
| 光线 | 单侧 45° 硬光，另一侧沉入黑暗 |
| 构图 | 主体居中偏下，上方留空给时钟或文案 |
| 字体 | 英文 Cormorant Garamond，中文思源宋体 Light，金色小字 |

## 文案与互动

- **标题模板**：「碎过的地方，会发光 · No.[编号]」或「建议每个心碎过的人都换上这张壁纸」。
- **正文模板**：一句金缮小知识 + 一句情绪句 + 「高清原图在评论区」。
- **互动钩子**：「评论区告诉我你想修补什么，下一件就做它」。

## 后期要点

- 金线单独提亮并加一点外发光（辉光 5–10%），其余部分压暗。
- 黑场必须是纯黑，用曲线将暗部拉到 0，OLED 屏上会与手机边框融为一体。
- 裂纹太密时，直接在对话里说 "Keep everything the same, but reduce the cracks to only four."
