## 角色一致性方法（GPT Image）

1. 每个角色先生成一张最满意的正面全身图，存为"定妆图"。
2. **之后每次生成都在同一个对话里上传定妆图**，提示词里加一句："Use the uploaded reference image to keep the character exactly the same."
3. 只改一处时用对话式修改，不要重新生成，例如："Keep everything the same, but change the expression to crying."
4. 做不到 100% 一致时，优先保证三个地方不变：天线、眼睛、体内小物件。这三个就是角色的识别点。

## GIF 表情包制作流程

GPT Image 擅长一次出一整张"贴纸表"，并能直接写上中文配字，这一步比逐张生成快得多。

1. **一次生成整套静态表情**（上传定妆图）：

```
A square sticker sheet with 16 stickers arranged in a clean 4×4 grid on a transparent background. Every sticker shows the same character from the uploaded reference image: [角色固定描述]. Each sticker has a different expression and pose, with a short Chinese caption below it in a rounded, bold, cute font, white text with a [pink] outline. The captions in order: 早安, 晚安, 收到, 哭哭, 开心, 害羞, 生气, 震惊, 加油, 爱你, 无语, 摸鱼, 饿了, 拜托, 谢谢, 拜拜. Leave even spacing between the stickers so they are easy to cut apart. 3D designer-toy render style.
```

2. **逐字核对配字**，有错字就让它单独重画那一格；然后把 16 格裁开（Photoshop 切片或任意九宫格切图工具）。
3. **做成动态**：把单张丢进可灵 / 即梦图生视频，提示词：`the character [动效提示词], cute bouncy jelly motion, camera static, plain white background, seamless loop`，生成 5 秒。
4. **截取循环段**：用剪映取动作最完整的 1–2 秒；首尾帧不接近时，用"正放 + 倒放"拼成循环。
5. **转 GIF**：用在线工具 ezgif，或下面这条 ffmpeg 命令（15 帧、240×240、自带调色板保证画质）：

```bash
ffmpeg -i input.mp4 -vf "fps=15,scale=240:240:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" -loop 0 output.gif
```

6. **上架**：微信表情通过 [微信表情开放平台](https://sticker.weixin.qq.com) 提交审核。尺寸、单张体积、张数等规格请以平台后台的最新要求为准；AI 生成作品能否上架也先看平台当前规则。
