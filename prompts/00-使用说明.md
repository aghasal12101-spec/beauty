# 使用说明（GPT Image 版）

本套提示词已针对 GPT Image（ChatGPT 生图或 OpenAI 图像 API）改写：去掉了 Midjourney 的 `--ar`、`--style`、`--no` 等参数，改成完整的自然语言描述。方括号 `[ ]` 里是要替换的变量。

## GPT Image 与 Midjourney 的主要区别

| 事项 | GPT Image 的做法 |
| --- | --- |
| 画幅 | 写在提示词第一句，如 "A vertical 9:16 phone wallpaper"。API 竖版可选 1024×1536（2:3），出图后裁成 9:16；ChatGPT 里直接说"竖版 9:16"即可 |
| 负面提示词 | 没有单独的负面栏，写成句子放在末尾："No text, no watermark, no border." |
| 风格统一 | 在同一个对话里连续生成；或上传第一张满意的图，加一句 "Match the style, color grading and lighting of the reference image." |
| 画面文字 | GPT Image 能较准确地画出文字。英文编号、标题可以直接让它画；中文建议 2–6 个字的短词，长句仍然后期加 |
| 局部修改 | 不用重新生成，直接在对话里说："Keep everything the same, but make the gold lines thinner." |
| 透明背景 | 表情包、贴纸可以要求 "transparent background"（API 设 `background: transparent`，输出 PNG） |
| 偏色 | 如果画面整体偏黄，末尾加 "neutral white balance, no warm color cast." |

## 通用结构

每条提示词按这个顺序写：**画幅与用途 → 主体 → 场景 → 光线 → 色彩 → 风格与镜头 → 构图留白 → 禁止项**。同一栏目内只换主体，其余部分固定，栏目的辨识度就来自这些固定部分。

## 画幅对应

## 通用后期流程

1. 每个栏目选一张最满意的图作为"风格参考图"，之后每次生成都上传它。
2. 放大到 4K，套栏目专属调色预设。
3. 加 2–4% 颗粒噪点，削弱 AI 的塑料感。
4. 编号、标题位置和字体每个栏目固定。
5. 发布时勾选"AI 生成内容"标识。

## 动态版说明

GPT Image 只出静态图。需要动态壁纸或 GIF 时，先用 GPT Image 出静图，再交给可灵、即梦等图生视频工具。各栏目文件里的"动效提示词"就是给这一步用的。
